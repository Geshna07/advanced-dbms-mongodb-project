# Advanced DBMS - Multi-Domain Data Intelligence System

## Project Overview

This project is developed as part of the Advanced Database Management Systems course using MongoDB.

The project demonstrates the design, creation, management and analysis of multiple domain-specific NoSQL databases using MongoDB Atlas.

## Domains

The project contains six independent databases:

1. Smart Campus AI
2. Agri Market AI
3. Healthcare Intelligence
4. Smart E-Commerce
5. Smart Travel
6. Smart Finance

## Database Structure

Each database contains:

- 10 collections
- 60 documents per collection
- 10+ fields per document
- Structured and nested data
- Arrays and different MongoDB data types
- Reference IDs between related collections

## Technologies

- MongoDB

- JavaScript

- GitHub

- Database and collection creation
